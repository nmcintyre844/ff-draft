# ff-draft

Fantasy football draft order lottery — a single-page static web app.

## Usage

Open `index.html` in a browser, or host it on any static host (it's a single
self-contained file with no dependencies or build step). Add each league
manager's name, then hit **Run the Lottery**. Picks are revealed one at a
time from the last pick up to #1, slot-machine style, with confetti for the
first overall pick. Names are remembered locally between visits.
